# Spec 001: public protocol v0.1

Status: retired

- Accepted: 2026-10-09
- Retired: 2026-10-09
- Scope: first public clean-room implementation

## Decision

Publish a platform-neutral analytical protocol whose root `SKILL.md` is the portable entrypoint. The default result is a concise response; a predefined Markdown dossier is an explicit output mode. Theoretical grounding is visible through concept-level warrants and a source registry rather than hidden behind an oracle voice.

## Change-shape matrix

| Surface | Changed? | Consequence |
|---|---:|---|
| User-visible behavior | Yes | Defines two output profiles and required limitations. |
| Persisted schema | Yes | Adds an optional, versioned event-interchange schema; no user data store. |
| External/provider contract | No | No provider or network is required. |
| Privacy/security | Yes | Conversation content is private by default; public examples are fictional. |
| Lifecycle/state | Yes | Dossier files are written only on explicit request. |
| Setup/runtime | Yes | Root skill is portable; optional host metadata is additive. |
| Normative docs | Yes | `CONTRACTS.md` is the authority for observable behavior. |
| Cross-repository coupling | Construction only | The method is rebuilt from public-safe abstractions; no runtime or history coupling. |

## Required slice

1. Create the clean repository with no shared history.
2. Define input, evidence, method, theory-warrant, output, and privacy contracts.
3. Supply concise and dossier output profiles.
4. Register a deliberately small Lacanian concept set plus conversation-analysis bridge concepts.
5. Add six fictional cases covering a negative control, positional shift, relay, failed/effective repair, organizing signifier, and epistemic-provenance correction.
6. Validate structure and prohibited overclaim expectations without golden-prose tests.
7. Document current theory sources and their reuse status.
8. Verify packaging, tests, repository history, and trace cleanliness.

## Deferred

- Four discourses as a default analytic grid
- Imaginary/Symbolic/Real mapping as a required layer
- Objet petit a, jouissance, fantasy, or clinical structure classification
- Quantitative scoring or automated model evaluation
- Platform-specific transcript importers
- Publication or remote creation

- Eight unit tests pass.
