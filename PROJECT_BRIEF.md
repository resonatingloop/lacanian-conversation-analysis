# Project brief

## One line

An evidence-led, platform-neutral protocol for Lacanian-style analysis of ordered conversations.

## Purpose

The project helps an analyst reconstruct what utterances do to the relational geometry of a conversation: who addresses whom, where knowledge is located, which signifiers organize uncertainty, how a rupture develops, and why a repair succeeds or fails.

It combines sequential discipline from conversation analysis with a small, explicitly warranted set of Lacanian concepts. It is neither a transcript mood ring nor a machine for diagnosing speakers.

## Intended users

- researchers studying human, agent, or mixed conversations;
- facilitators examining rupture, repair, relay, or epistemic provenance;
- analysts who want a Lacanian reading that remains answerable to the event record;
- skill authors who need a platform-neutral analysis contract.

## Public boundary

The repository contains only method, templates, schemas, tests, and wholly fictional examples. It contains no private conversation, derived private case analysis, private identifier, or reconstructive paraphrase from the archive in which the protocol was developed.

## Maturity

Version `0.1` is experimental. Its six synthetic cases test distinct interactional structures and failure modes. A stable `1.0` requires validation on an openly publishable, differently structured corpus and documented revision from that comparison.

## Non-goals

- infer stable personalities, diagnoses, clinical structures, or inner states;
- replace close reading with keyword counts;
- call every repeated word a master signifier;
- treat chronology alone as causality;
- publish, upload, or persist supplied conversations without an explicit request;
- require one vendor, model, platform, or tool runtime.
