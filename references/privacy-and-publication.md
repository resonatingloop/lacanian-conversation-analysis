# Privacy and publication

## Default posture

A conversation supplied for analysis is private working material unless the user explicitly states otherwise. Permission to analyze is not permission to publish, upload, redistribute, train on, or retain.

The protocol can run entirely in context. It does not require a network connection, external service, durable database, or telemetry.

## Files

Return analysis in the response by default. Write a dossier only when the user explicitly requests file output and supplies or accepts a destination. Do not silently create a transcript cache, normalized copy, lookup table, or sibling source file.

When a host persists conversations independently of this skill, describe that as host behavior rather than a guarantee made by the protocol.

## Quotations

Analytical necessity and publication permission are different questions.

- In private analysis, quote only the span needed to make a claim inspectable.
- In potentially public analysis, use opaque local references and non-reconstructive paraphrase by default.
- A direct quotation requires explicit, case-specific publication permission.
- A set of individually short paraphrases can still reconstruct a private exchange; assess the set, not only each sentence.

## Identifiers and provenance

Keep supplied IDs exact inside the authorized analysis boundary. Do not invent identities behind pseudonyms, merge similar speakers, or derive stable public identifiers from private content. Unknown provider, model, version, reply target, or timestamp fields remain unknown.

## Public examples

Repository examples must be wholly fictional or explicitly licensed for redistribution. A text being accessible on the web does not make it safe to bundle. For citation-only theory sources, store bibliographic metadata and links, not copied full text.

## Publication check

Before releasing an analysis, inspect the complete artifact for:

- direct quotations without case-specific permission;
- names, handles, timestamps, IDs, hashes, or URLs that enable reidentification;
- paraphrase sequences that reconstruct the exchange;
- source-to-public lookup tables;
- unsupported claims of consent, authorship, identity, or durable interior state;
- attachments or metadata inherited from the source.

If the public artifact needs evidentiary references, use opaque analysis-local references and retain any private lookup only in the authorized private workspace.
